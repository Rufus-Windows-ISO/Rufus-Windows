- RISC-V 64 on UEFI:NTFS
- Silent Windows install guards
- Cancel during write retries
- Compressed image extract progress
- ezxml parser overflow fix
- Silent install stuck at 75 percent

## FAQ

**rufus for linux?**
It runs on Windows. Target media can be Ubuntu or other linux ISOs.

**rufus mac?**
No native Mac build. This zip is Windows x64 / x86 / ARM64.

## Requirements
Windows 8 or later. USB stick. ISO or IMG.
